# 项目自定义文件

不同项目在需要自己的样式、功能代码、图片或其他文件时，可以speical文件夹中添加或定义目标文件。在没有指定文件时自行创建即可。

## 项目自定义 css 文件

项目 css 文件地址：speical/css/\*.css

目前 Default，pageList，detail 文件有自定义 css 文件

-   common.css 为通用 css，每个页面都会引用。

-   home.css 为首页 css。

-   其他 css 与地址 html 文件名对应

## 项目自定义 js 文件

项目 js 文件地址：speical/js/\*.js

目前 Default，pageList，detail 文件有自定义 css 文件

-   common.js 为通用 js，每个页面都会引用。

-   home.js 为首页 js。

-   其他 js 与地址 html 文件名对应

## 项目自定义 图片

项目图片存放路径：speical/images

# 配置中心代码更新

配置中心代码更新为文件夹直接覆盖，所以不建议修改在配置文件夹下文件。

目前覆盖的文件夹有：

- assets
- components
- libs
- template
- tools
- tools-igw
- utils
