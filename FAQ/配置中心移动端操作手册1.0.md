### 一、配置流程

移动端的配置流程与云端的配置流程大致相同。新增功能点同步后，在定义菜单的时候在“终端操作”中新增菜单。移动端的组件嵌套关系图和实际配置效果图如下：

![](markune-asset://92abe989c1e532710b32226da615534c68a91951191793fcbee87d12c57b2baa)![](markune-asset://9b6239735b627623c14b2d8b8abb3dac4bc686bc96261d3af4776837317e6ade)

在设置好项目，定义好功能、配置好类信息、关联表、操作列表之后，新增容器。

1. 新增UcContainer

UcContainer在移动端中作为最外层的容器，在其中可以引用其他容器来实现不同的页面。

1. 新增UcPageTitleContainer

UcPageTitleContainer容器的作用是为页面增加Title，需要配置属性TitleRSCode。在右侧可配置一个搜索按钮或者其他按钮。

![](markune-asset://d9ec4d26f496c945dc1de6fd966c1bf363b13e8188c724439d411d88e73f92b1)

### 四、UcButton/UcButtonContainer

UcButtonContainer:为按钮组容器,可以在UcButtonContainer中新增多个UcButton子控件，

通过在RelativeContainer属性中填写关联的容器的ID来实现获取操作权限.

属性:


|                   |         |                                                                                                           |
| ----------------- | ------- | --------------------------------------------------------------------------------------------------------- |
| 属性                | 值       | 备注                                                                                                        |
| RelativeContainer | 如C61471 | 关联容器ID，用来判断权限等关联容器的ID属性的值，如果是目标容器是UcContainer，则与菜单权限相同；如果是UcGridview，则与行数据具体的权限相同；如果是UcForm，则与该Form的权限相同。 |

#### ExtraConfig的使用

ChartType只是提供了默认基础的配置项，如果有和基础图表配置项不同或需要更改的地方，还是需要在ExtraConfig中单独配置。ExtraConfig的配置项和ChartType默认配置项的合并规则遵循相同属性覆盖，默认配置未有新增的原则。ExtranConfig 的配置项格式参考echart文档（[https://echarts.apache.org/examples/zh/index.html）](https://echarts.apache.org/examples/zh/index.html）)

示例：配置ChartType 为circular-pie 为图一的显示形式，如要配置成图二的显示形式可在ExtraConfig中添加以下配置

{

legend: {

show:false,

},

color:\['#5470c6', '#91cc75'\],

title:{

subText:”总数”,

},

series:\[

{

radius: \['80%', '90%'\],

}

\]

}
