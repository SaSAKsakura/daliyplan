## 7. 第六层：界面构造模型（ui_）

> **第六层：界面构造模型**（对位平台「前端交互平台」）：前端（Vue 3 + elementUI）解析本层配置 JSON **动态构造页面**——页面、组件、布局、数据源、数据绑定、界面动作、字段渲染配置。**前缀约定**：本章各表用 `ui_`。界面**不直连数据模型**，数据一律经 `prod_api` 存取（数据绑定见 7.4，数据源见 7.7）。**域归属**：本章 7 张表属**研发固化域**（`ddd`）——
界面配置属**产品交付的界面模板**（研发阶段固化、跨客户复用），其**运行子集**在发布时快照同步到 `app` 供前端引擎**只读**；
客户的界面差异经覆盖登记（`app_cfgoverride`，见 1.7/8.20）表达；最终生效配置经多层合并导出为 JSON 文件供前端渲染（见 1.7 节）。

### 7.1 ui_page — 页面定义

> 页面（Page）是前端路由与渲染的顶层单元，由页面类型决定布局骨架（列表页/表单页/详情页/仪表盘/向导/树页），可挂接业务场景与主业务对象。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `page_id` | integer | PK | 主键，序列 `seq_ui_page` |
| `parent_page_id` | integer | | → `ui_page.page_id`（父页面，自引用，表达页面层级嵌套；根为空） |
| `row_uuid` | uuid | UN, NOT NULL | 全局行标识（UUID v4） |
| `page_code` | varchar(64) | UN, NOT NULL | 页面编码（如 `PG_ORDER_LIST`） |
| `page_name` | varchar(128) | NOT NULL | 页面名称（如"订单列表"） |
| `ui_pagetype_dict` | varchar(64) | NOT NULL | 页面类型（字典）：`LIST`（列表页）/`FORM`（表单页）/`DETAIL`（详情页）/`DASHBOARD`（仪表盘）/`WIZARD`（向导页）/`TREE`（树页）。`_dict` 字典引用 |
| `scenario_id` | integer | | → `prod_scenario.scenario_id`（页面服务的业务场景，逻辑关联，见 2.3） |
| `sub_scenario_id` | integer | | → `prod_subscenario.sub_scenario_id`（细化到子场景，见 2.4） |
| `aggregate_id` | integer | | → `cdm_aggregate.aggregate_id`（页面主业务对象，见 3.1） |
| `route_path` | text | | 前端路由（如 `/order/list`，不定长，对齐 `_path` → `text` 后缀规范） |
| `layout_json` | jsonb | | 页面级布局配置（栅格/标签页/分栏骨架） |
| `description_txt` | text | | 页面说明 |
| `sort_order` | integer | | 排序 |
| `create_by` | integer | NOT NULL | 创建人（app.user_id） |
| `create_ts` | timestamp | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `update_by` | integer | NOT NULL | 最后修改人（app.user_id） |
| `update_ts` | timestamp | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 最后修改时间 |
| `delete_flag` | smallint | NOT NULL, DEFAULT 0 | 逻辑删除标志 |
| `version_cnt` | integer | NOT NULL, DEFAULT 0 | 乐观锁版本号 |

> **设计要点**：`page_code` 全局唯一；`layout_json` 承载页面骨架，组件实例细节在 `ui_page_component.props_json`（见 7.3）——两层 JSON 分工：页面管骨架、组件实例管细节。

> 可复用的**组件模板**：对 elementUI 组件（及平台封装组件）的建模登记，`props_json` 声明组件可配置属性，供页面布局实例化引用。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `component_id` | integer | PK | 主键，序列 `seq_ui_component` |
| `row_uuid` | uuid | UN, NOT NULL | 全局行标识（UUID v4） |
| `component_code` | varchar(64) | UN, NOT NULL | 组件编码（如 `CPT_EL_TABLE`、`CPT_ORDER_TABLE`） |
| `component_name` | varchar(128) | NOT NULL | 组件名称（如"表格组件"、"订单表格"） |
| `ui_componenttype_dict` | varchar(64) | NOT NULL | 组件类型（字典）：`TABLE`/`FORM`/`INPUT`/`SELECT`/`DATEPICKER`/`DIALOG`/`STEPS`/`CARD`/`TREE`（对应 elementUI 组件族）。`_dict` 字典引用 |
| `parent_component_id` | integer | | → `ui_component.component_id`（组件继承/派生，如"订单表格"派生自"通用表格"） |
| `props_json` | jsonb | | 组件可配置属性定义（对齐 elementUI props） |
| `description_txt` | text | | 组件说明 |
| `create_by` | integer | NOT NULL | 创建人（app.user_id） |
| `create_ts` | timestamp | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `update_by` | integer | NOT NULL | 最后修改人（app.user_id） |
| `update_ts` | timestamp | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 最后修改时间 |
| `delete_flag` | smallint | NOT NULL, DEFAULT 0 | 逻辑删除标志 |
| `version_cnt` | integer | NOT NULL, DEFAULT 0 | 乐观锁版本号 |

> **设计要点**：组件库分两层——平台基础组件（elementUI 登记为模板）与业务派生组件（`parent_component_id` 继承扩展）；字段渲染配置（`ui_fieldconfig`，见 7.6）按控件类型引用本表。

### 7.3 ui_page_component — 页面-组件布局

> 页面内**组件实例的布局树**：页面上每个实际渲染的组件实例（含嵌套），经 `parent_page_component_id` 构成父子树形结构（如"表单页 → 表单 → 输入框组"）。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `page_component_id` | integer | PK | 主键，序列 `seq_ui_page_component` |
| `row_uuid` | uuid | UN, NOT NULL | 全局行标识（UUID v4） |
| `page_id` | integer | NOT NULL | → `ui_page.page_id`（所属页面，逻辑关联，见 7.1） |
| `component_id` | integer | NOT NULL | → `ui_component.component_id`（实例化的组件模板，见 7.2） |
| `parent_page_component_id` | integer | | → `ui_page_component.page_component_id`（父组件实例，构成布局树；根节点为空） |
| `slot_code` | varchar(64) | | 挂接插槽位置（如 `header`/`footer`/`default`） |
| `props_json` | jsonb | | 实例级属性覆盖（标题/列定义/禁用态等，优先于模板默认值） |
| `visible_json` | jsonb | | 显隐/禁用条件表达式（如 `{ "expr": "status == 'DRAFT'" }`） |
| `sort_order` | integer | | 排序 |
| `create_by` | integer | NOT NULL | 创建人（app.user_id） |
| `create_ts` | timestamp | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `update_by` | integer | NOT NULL | 最后修改人（app.user_id） |
| `update_ts` | timestamp | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 最后修改时间 |
| `delete_flag` | smallint | NOT NULL, DEFAULT 0 | 逻辑删除标志 |
| `version_cnt` | integer | NOT NULL, DEFAULT 0 | 乐观锁版本号 |

> **设计要点**：`page_id + parent_page_component_id + slot_code + sort_order` 表达布局树节点位置；`props_json` 覆盖 `ui_component.props_json` 默认值（实例级优先）；数据绑定与动作均挂**组件实例**（见 7.4/7.5），不直接挂模板。

### 7.4 ui_databinding — 数据绑定

> 组件实例与**数据源/后端能力**的数据通道：列表加载、表单回显、提交保存均绑定到 `ui_datasource`（经其 `api_id` 引用能力端点），界面不直连数据模型——这是「前端读配置、后端出数据」的关键约束。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `binding_id` | integer | PK | 主键，序列 `seq_ui_databinding` |
| `row_uuid` | uuid | UN, NOT NULL | 全局行标识（UUID v4） |
| `page_component_id` | integer | NOT NULL | → `ui_page_component.page_component_id`（绑定的组件实例，见 7.3） |
| `datasource_id` | integer | | → `ui_datasource.datasource_id`（绑定的数据源，见 7.7；为空时兼容存量语义，直接挂 `api_id`） |
| `api_id` | integer | | → `prod_api.api_id`（数据来源/提交目标，见 6.1；`datasource_id` 非空时经数据源间接引用，可空） |
| `ui_bindingtype_dict` | varchar(64) | NOT NULL | 绑定类型（字典）：`LOAD`（加载）/`SUBMIT`（提交）/`VALIDATE`（校验）。`_dict` 字典引用 |
| `param_json` | jsonb | | 参数映射（界面字段 ↔ 操作入参 `input_json` 的映射表达式） |
| `create_by` | integer | NOT NULL | 创建人（app.user_id） |
| `create_ts` | timestamp | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `update_by` | integer | NOT NULL | 最后修改人（app.user_id） |
| `update_ts` | timestamp | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 最后修改时间 |
| `delete_flag` | smallint | NOT NULL, DEFAULT 0 | 逻辑删除标志 |
| `version_cnt` | integer | NOT NULL, DEFAULT 0 | 乐观锁版本号 |

> **设计要点**：
> - **绑定唯一约束** = `page_component_id + ui_bindingtype_dict + 数据源定位列`（`datasource_id` 非空时用 `datasource_id`，为空时回退 `api_id`；约束名 `uk_ui_databinding_component_source_type`）
> - `param_json` 与操作 `input_json`/`output_json`（见 6.1）契约对齐；`LOAD` 绑定在前端解析为请求，`SUBMIT` 绑定先触发校验时序（见 9.3）再调用
> - **数据源语义（v3.0）**：页面级数据通道统一经 `ui_datasource`（见 7.7）建模——组件绑定引用数据源，数据源承载 schema 聚合/级联依赖/刷新触发/缓存/分页，绑定不再承担数据源推导

### 7.5 ui_action — 界面动作

> 组件实例上的**交互动作**（按钮/事件）：调用服务、打开页面、状态流转、导出等，是「用户点击 → 后端执行」的配置化落点。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `action_id` | integer | PK | 主键，序列 `seq_ui_action` |
| `row_uuid` | uuid | UN, NOT NULL | 全局行标识（UUID v4） |
| `page_component_id` | integer | NOT NULL | → `ui_page_component.page_component_id`（动作所属组件实例，见 7.3） |
| `action_code` | varchar(64) | UN, NOT NULL | 动作编码（如 `ACT_SUBMIT_ORDER`） |
| `action_name` | varchar(128) | NOT NULL | 动作名称（如"提交订单"） |
| `ui_actiontype_dict` | varchar(64) | NOT NULL | 动作类型（字典）：`CALL_SERVICE`（调用服务）/`OPEN_PAGE`（打开页面）/`STATE_TRANS`（状态流转）/`EXPORT`（导出）/`CUSTOM`（自定义脚本）。`_dict` 字典引用 |
| **`target_api_id`** | integer | | → `prod_api.api_id`（`CALL_SERVICE`/`EXPORT` 目标能力端点，见 6.1） |
| `target_page_id` | integer | | → `ui_page.page_id`（`OPEN_PAGE` 目标页面，见 7.1） |
| `state_trans_code` | varchar(64) | | `STATE_TRANS` 目标状态（状态字典项，如 `SUBMITTED`）——**触发平台内置 `wf_*` 工作流体系的状态流转**，本模型不承载流程定义（见 6.1 服务类型 WORKFLOW 说明与修订方案 D12） |
| **`menu_op_id`** | integer | | → `prod_menu_op.menu_op_id`（**鉴权依据**：动作对应的菜单操作权限点，见 6.3；为空表示不控权；以 `menu_op_id` 外键关联，非 `permission_code` 字符串软关联） |
| `confirm_txt` | text | | 二次确认文案（如"确认提交该订单？"，非空时前端先弹确认） |
| `sort_order` | integer | | 排序 |
| `create_by` | integer | NOT NULL | 创建人（app.user_id） |
| `create_ts` | timestamp | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `update_by` | integer | NOT NULL | 最后修改人（app.user_id） |
| `update_ts` | timestamp | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 最后修改时间 |
| `delete_flag` | smallint | NOT NULL, DEFAULT 0 | 逻辑删除标志 |
| `version_cnt` | integer | NOT NULL, DEFAULT 0 | 乐观锁版本号 |

> **设计要点**：
> - 动作目标按 `ui_actiontype_dict` 选填（操作/页面/状态三选一）
> - **两个外键各司其职**：`target_api_id` → `prod_api` 决定**动作实际调用哪个能力**；
>   `menu_op_id` → `prod_menu_op` 决定**该动作受哪个权限点控权**。
>   二者**解耦**——能力调用链本就不经权限点（见 6.3）。
> - `menu_op_id` 为**外键**而非编码字符串，解决了原 `permission_code` 跨表引用**无唯一约束保障**的隐患
> - `STATE_TRANS` 的目标状态与 `prod_activity.prod_tostate_dict`（见 2.5）的状态字典对齐，形成「场景分析状态流转 → 界面动作」的配置闭环
> - **工作流能力边界（v3.0 声明）**：流程引擎走平台内置 `wf_*` 体系，`STATE_TRANS` 定义为「触发 wf_* 状态流转的界面动作」（联动流程定义以 `wf_code` 文本引用），本模型不新建工作流表（见修订方案 D12）

### 7.6 ui_fieldconfig — 字段渲染配置

> **实体属性 → 界面控件**的渲染配置：字段用什么控件、占几格、何时显隐——与属性 `config_json`（业务配置，见第 9 章）分离：`config_json` 管**值怎么约束**（字典/精度/校验），本表管**值怎么呈现**（控件/布局/显隐）。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `fieldconfig_id` | integer | PK | 主键，序列 `seq_ui_fieldconfig` |
| `row_uuid` | uuid | UN, NOT NULL | 全局行标识（UUID v4） |
| `attribute_id` | integer | | → `cdm_entity_attribute.entity_attribute_id`（实体属性渲染配置，见 3.4） |
| `vo_attribute_id` | integer | | → `cdm_valueobject_attribute.valueobject_attribute_id`（值对象属性渲染配置，见 3.5；与 `attribute_id` 二选一） |
| `component_id` | integer | | → `ui_component.component_id`（指定渲染控件，见 7.2；为空按 `ui_rendermode_dict` 取默认控件） |
| `ui_rendermode_dict` | varchar(64) | NOT NULL | 渲染模式（字典）：`TEXT`（文本）/`SELECT`（下拉）/`DATE`（日期）/`NUMBER`（数值）/`SWITCH`（开关）/`UPLOAD`（上传）。`_dict` 字典引用 |
| `grid_span_cnt` | integer | | 栅格跨度（1~24，elementUI el-col span） |
| `display_json` | jsonb | | 显隐/禁用/只读规则（如 `{ "editableOnUpdate": false }`） |
| `description_txt` | text | | 配置说明 |
| `create_by` | integer | NOT NULL | 创建人（app.user_id） |
| `create_ts` | timestamp | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `update_by` | integer | NOT NULL | 最后修改人（app.user_id） |
| `update_ts` | timestamp | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 最后修改时间 |
| `delete_flag` | smallint | NOT NULL, DEFAULT 0 | 逻辑删除标志 |
| `version_cnt` | integer | NOT NULL, DEFAULT 0 | 乐观锁版本号 |

> **设计要点**：`attribute_id`/`vo_attribute_id` 互斥（一个渲染配置只挂一类属性）；与属性 `config_json`（见 9.2）的分工——`config_json` 属领域侧业务语义（随属性走），本表属界面呈现（随页面渲染走），同一属性可在不同页面配置不同渲染。

### 7.7 ui_datasource — 页面级数据源定义

> **数据源（Data Source）**：**页面级可复用数据通道**（v3.0 新增，对应前端契约 YiDataSource 概念，修复 B1-5 阻断缺口）。数据源承载页面上一次数据交互的完整语义：
> - 能力范围：加载/提交/级联/选项的数据契约（`schema_json`）、级联依赖、刷新触发、缓存与分页
> - 挂接链路：组件实例经 `ui_databinding.datasource_id`（见 7.4）挂接数据源 → 数据源经 `api_id` 调用能力端点（`prod_api`）
> - **前端不直连数据模型**约束不变

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `datasource_id` | integer | PK | 主键，序列 `seq_ui_datasource` |
| `row_uuid` | uuid | UN, NOT NULL | 全局行标识（UUID v4） |
| `page_id` | integer | NOT NULL | → `ui_page.page_id`（所属页面，逻辑关联，见 7.1） |
| `datasource_code` | varchar(64) | UN, NOT NULL | 数据源编码（如 `DS_ORDER_LIST`） |
| `datasource_name` | varchar(128) | NOT NULL | 数据源名称 |
| `ui_datasourcetype_dict` | varchar(64) | NOT NULL | 数据源类型（字典）：`LOAD`（加载）/`SUBMIT`（提交）/`LINKAGE`（级联）/`OPTIONS`（选项）。`_dict` 字典引用 |
| `api_id` | integer | NOT NULL | → `prod_api.api_id`（实现载体，见 6.1） |
| `schema_json` | jsonb | | 数据契约（字段/主键/分页/排序，对齐操作 `input_json`/`output_json`） |
| `depends_on_json` | jsonb | | 依赖链（级联源数据源/字段映射，如 `[{ "source": "DS_CUSTOMER", "map": {"customer_id": "query.customer_id"} }]`） |
| `refresh_trigger_json` | jsonb | | 刷新触发（事件/动作完成后刷新本数据源，联动表达见下） |
| `cache_flag` | smallint | NOT NULL, DEFAULT 0 | 缓存标志 |
| `page_size_uom` | integer | | 默认分页大小（`_uom` 计量值） |
| `enable_flag` | smallint | NOT NULL, DEFAULT 1 | 启用标志 |
| `sort_order` | integer | | 排序 |
| `description_txt` | text | | 说明 |
| `create_by` | integer | NOT NULL | 创建人（app.user_id） |
| `create_ts` | timestamp | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `update_by` | integer | NOT NULL | 最后修改人（app.user_id） |
| `update_ts` | timestamp | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 最后修改时间 |
| `delete_flag` | smallint | NOT NULL, DEFAULT 0 | 逻辑删除标志 |
| `version_cnt` | integer | NOT NULL, DEFAULT 0 | 乐观锁版本号 |

> **设计要点**：
> - `datasource_code` 全局唯一；`page_id + ui_datasourcetype_dict` 表达页面内数据源集合，页面级共享（多组件挂同一数据源）；
> - **联动（B1-3）**：级联经 `depends_on_json` 声明（源数据源 + 字段映射），刷新经 `refresh_trigger_json` 声明（`ui_action` 动作完成后触发目标数据源刷新）——联动无需独立表；
> - **事件（B1-4）**：组件事件绑定经 `ui_action`（见 7.5）表达，事件处理后经 `refresh_trigger_json` 驱动数据源刷新；
> - **数据源与绑定的分工**：`ui_datasource` 管「页面级数据怎么来」，`ui_databinding` 管「组件实例挂哪个数据源、参数怎么映射」（`datasource_id` 优先，可空）；
> - 本表属**运行配置域**（`app`），发布同步生成，前端运行时只读；与 `prod_api` 契约单向对齐（数据源不直连数据模型）。
