## 1. 概述

YiHtmlTemplate 是低代码配置中心的新控件，用于实现**前端代码存数据库、动态渲染**的场景。适用于标准配置组件（表单、表格、列表）无法覆盖的复杂页面布局和自定义交互区域。

### 1.1 核心概念


| 概念               | 说明                                                         |
| ---------------- | ---------------------------------------------------------- |
| **模板（Template）** | 前端 HTML/JS 代码字符串，存储在 `cfg_template` 表                      |
| **版本（Version）**  | 发布时生成快照，自增编号 v1/v2/v3，**template\_str（代码）不可修改**；引用的资源始终取最新 |
| **资源（Resource）** | 模板引用的图片、CSS、JS 等静态文件                                       |
| **草稿（Draft）**    | 编辑中的模板内容，可反复覆盖                                             |
| **发布（Publish）**  | 将草稿内容复制到版本表生成快照                                            |


### 1.2 适用场景

- 标准组件配置覆盖不了的复杂页面区域
- 需要自定义 HTML/CSS/JS 交互的区块
- 多个业务功能共用同一套前端界面，各自使用不同数据源

#### 字段说明


| 字段     | 必填  | 说明                        |
| ------ | --- | ------------------------- |
| 模板代码   | 是   | 业务唯一标识，创建后不可修改            |
| 模板名称   | 是   | 模板显示名称                    |
| 业务场景描述 | 是   | 说明该模板的用途和业务背景             |
| 产品代码   | 否   | 从 `scr_product` 下拉选择，用于归类 |
| 模板内容   | 否   | HTML/JS 代码，前端动态渲染         |
| 数据格式   | 否   | JSON Schema 描述模板期望的数据结构   |


#### 资源引用

模板代码中引用资源的方式：使用 `file_guid` 标识资源。

```
<img src="resource://{file_guid}">
```

操作步骤：

1. 点击"选择资源"按钮
2. 从资源库中选取需要的资源文件
3. 选中的资源出现在引用资源列表中
4. 在模板代码中使用 `resource://{file_guid}` 引用

#### 效果图

效果图用于在模板列表页展示模板预览。通过明细页右上角 UcPhoto 控件上传和管理，走 `fs_file` 标准路径。操作方式与员工证件照相同。

### 2.4 保存与发布

#### 保存草稿

- 点击"保存草稿"按钮
- 内容写入 `cfg_template` 表，覆盖当前草稿
- 不生成版本，不影响线上已发布的版本
- 可反复保存，多次覆盖

#### 发布

- 点击"发布"按钮
- 系统自动对比当前草稿与最新版本：
- **有改动**：生成新版本号（v1 → v2 → v3，自增），将草稿内容+资源关联复制到版本历史表
- **无改动**：提示"未做任何改动，无需发布"
- 发布后版本的 template\_str（代码）不可修改，只能回切

#### 版本历史

版本历史在模板编辑页的 **UcTab** 中，路径为：基本信息 → 版本历史 Tab。

- 版本历史列表展示：版本号、发布时间、变更说明
- 点击"查看" → 进入版本明细页，预览该版本的代码和资源（只读）
- 版本明细页底部有"恢复草稿"按钮 → 确认后内容恢复到草稿区 → 手动发布
- 回切不会直接上线，恢复到草稿后需要手动发布

### 3.3 上传文件

1. 点击"上传文件"按钮
2. 在弹出的对话框中选择文件
3. 点击"确定上传"
4. 上传成功后，文件显示在资源列表中

**支持的格式：** JPG、JPEG、PNG、GIF、SVG、CSS、JS、JSON（按配置）
**单个文件限制：** 20MB（按配置）

### 3.4 替换文件

替换功能通过 UcDSContainer 配置实现，不在本次接口范围内。当前可通过删除后重新上传完成替换。

### 3.5 删除文件

1. 点击目标文件的"删除"按钮
2. 系统自动检查**草稿关联**和**版本关联**
3. **草稿关联 &gt; 0**：提示"该资源被 X 个模板草稿引用，请先移除引用后再删除"
4. **版本关联 &gt; 0**：弹出强提示"该资源被 N 个已发布版本引用，删除将影响线上展示，确认？" 用户确认后执行删除
5. 删除后已发布版本加载时显示"【资源不可用】"

### 3.6 查看引用范围

点击引用次数列的"查看"链接，弹出窗口显示引用了该资源的所有模板及版本：


## 4. 业务系统引用模板

### 4.1 引用方式

业务功能点通过 `RefContainer` 引用 YiHtmlTemplate，`templateCode` 属性使用三段式格式，**三段均必填**：

```
格式: {productCode}.{templateCode}.{versionNo}
示例: erow.YiReplyList.v3
```

各段说明：


| 段              | 必填  | 说明           |
| -------------- | --- | ------------ |
| `productCode`  | 是   | 产品代码，参与查询过滤  |
| `templateCode` | 是   | 对应模板的模板代码    |
| `versionNo`    | 是   | 版本号，必须指定具体版本 |


### 4.2 配置示例

```
RefContainer 配置:
  templateCode = "erow.YiReplyList.v3"
```

### 4.3 数据源配置

模板只负责 UI 渲染，数据源通过 `UcDSContainer` 配置。在业务功能点的容器配置中：

```
UcContainer（业务主容器）
  └── RefContainer（引用 YiHtmlTemplate）
        ├─ 属性: templateCode = "erow.YiReplyList.v3"
        ├─ 子控件: YiHtmlTemplate（前端渲染区）
        └─ 子控件: UcDSContainer（数据源定义）
             ├─ 数据查询：SQL / 存储过程 / 接口
             ├─ 数据操作：增删改
             └─ 前端本地缓存：支持
```

### 4.4 场景示例

同一套模板 `YiReplyList` 可以给多个业务使用，各自绑定不同数据源：


| 业务     | 模板          | 数据源      |
| ------ | ----------- | -------- |
| 售后工单回复 | YiReplyList | 查售后工单回复表 |
| 审批意见回复 | YiReplyList | 查审批意见表   |

## 5. 常见问题

### 5.1 模板代码写错了怎么办？

直接修改模板内容，点击"保存草稿"覆盖，确认无误后重新发布。发布后生成新版本，旧版本仍然保留在版本历史中。

### 5.2 发布后发现有问题怎么回退？

进入版本历史 → 选中要回退的版本（如 v2）→ 点击回切 → 内容恢复到编辑页草稿区 → 修改或直接发布 → 生成新版本（v4，内容同 v2）。

### 5.3 替换资源后模板没更新？

资源替换后 `file_hash` 更新，前端通过 hash 判断缓存是否过期。如果前端有缓存，刷新页面后会自动加载新资源。如果仍不更新，联系运维清理 Redis 对应 key，或等待 TTL 自然过期（模板内容缓存 30 天，资源缓存 1 小时）。

### 5.4 模板版本号怎么定的？

自动生成，首次发布为 v1，后续每次发布版本号 +1。版本号不可手动指定，不可修改已发布的版本。

### 5.5 可以删除有引用关系的资源吗？

取决于引用类型。**草稿关联**（当前编辑中的模板引用）会阻止删除，需先移除引用。**版本关联**（已发布版本的历史引用）不阻止删除，删除后该版本加载时显示"【资源不可用】"。

### 5.6 为什么我的模板显示"未发布"？

模板创建后需要手动点击"发布"才会生成版本。未发布的模板在列表页显示版本为"-"，业务系统无法引用。

## 6. 附录

### 6.1 表命名规则

所有新增表名遵循三段式规则：以下划线分隔，最多 3 段，可以 2 段或 3 段。


| 示例                    | 段数  | 说明    |
| --------------------- | --- | ----- |
| `fs_file`             | 2   | 文件表   |
| `fs_resource`         | 2   | 通用资源表 |
| `fs_resource_content` | 3   | 资源内容表 |


### 6.2 接口清单


| 接口                                                    | 用途          | 调用方    |
| ----------------------------------------------------- | ----------- | ------ |
| `POST /external/template/getTemplate`                 | 获取模板内容+资源列表 | 前端运行时  |
| `POST /external/resource/upload`                      | 上传资源文件      | 资源管理页面 |
| `GET /external/resource/download?bizType=yi_template` | 下载资源文件      | 前端运行时  |
| `POST /external/resource/delete`                      | 删除资源文件      | 资源管理页面 |
