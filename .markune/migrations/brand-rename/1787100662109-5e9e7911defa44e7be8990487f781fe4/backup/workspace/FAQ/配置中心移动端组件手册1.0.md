# 配置中心移动端组件手册1.0

本文按云端操作手册的组件展示方式整理移动端组件：先说明用途和适用场景，再列出核心属性、配置关系、效果示例及移动端差异。本文只收录《配置中心移动端操作手册1.0》中已有信息；原手册未说明的配置标记为“待补充”。

## 组件速查


| 分类   | 组件                               | 主要用途               | 移动端要点                          |
| ---- | -------------------------------- | ------------------ | ------------------------------ |
| 页面骨架 | `UcContainer`                    | 页面最外层容器，引用其他容器组成页面 | 通常引用标题、页签、列表和按钮组               |
| 页面骨架 | `UcPageTitleContainer`           | 展示返回图标、页面标题和右侧操作   | 右侧控件配置 `Position=right`        |
| 页面骨架 | `UcTabGroup` / `UcTab`           | 组织多个页签页面           | 可引用不同 `UcContainer`；角标配置待补充    |
| 数据展示 | `UcPageListContainer`            | 以卡片形式展示分页列表        | 引用 `UcCardContainer`；可通过存储过程取数 |
| 数据展示 | `UcCardContainer`                | 展示只读卡片并支持点击跳转      | `pageMode` 通常为 `VIEW`          |
| 数据编辑 | `UcFormDetailView`               | 新增、编辑和查看详情数据       | 编辑模式有分隔线，查看模式无分隔线              |
| 数据编辑 | `UcJsGridContainer`              | 多行编辑、弹窗选择和表单引用     | 属性及用法与云端大致相同                   |
| 操作控制 | `UcButtonContainer` / `UcButton` | 组织按钮、绑定权限并执行操作     | `RelativeContainer` 决定权限来源     |
| 业务能力 | `UcWorkFlow`                     | 在详情页展示和操作工作流       | 可与云端共用流程配置                     |
| 业务能力 | `UcFileContainer`                | 上传、列表或缩略图展示、预览文件   | 支持 PDF 和图片预览；iOS 不显示上传按钮       |
| 可视化  | `UcChartContainer`               | 展示饼图、柱状图、折线图等      | 支持默认图表类型与 ECharts 扩展配置         |
| 可视化  | `UcBannerContainer`              | 展示静态或动态轮播图         | 动态数据需返回文件定位字段                  |


## 页面组合关系

移动端页面以 `UcContainer` 为最外层容器。标题、页签、列表和按钮组通过引用关系组合，卡片作为列表的展示模板。

```text
UcContainer
├─ UcPageTitleContainer
├─ UcTabGroup
│  └─ UcTab / UcContainer
│     ├─ UcPageListContainer
│     │  └─ RefContainer → UcCardContainer
│     └─ UcButtonContainer
└─ 其他详情容器
```

## 典型页面展示

组件通过引用关系组合为完整页面。以下 6 类页面均来自原移动端手册；缺少完整页面截图的内容标记为“组合示意”。

### 卡片列表页

用于展示业务清单，支持标题、搜索、页签、卡片详情跳转和底部操作。

```text
UcContainer
├─ UcPageTitleContainer → UcImage（搜索，Position=right）
└─ UcTabGroup → UcContainer
   ├─ UcPageListContainer → RefContainer → UcCardContainer
   └─ UcButtonContainer
```


| 配置位置                                  | 关键值                        | 作用       |
| ------------------------------------- | -------------------------- | -------- |
| `UcPageTitleContainer.TitleRSCode`    | 标题资源代码                     | 设置标题     |
| `UcImage.ClientActions`               | `{"onclick":"showSearch"}` | 打开搜索     |
| `UcPageListContainer.ScopeCtnr`       | 查找容器 `CtnrUID`             | 关联查询     |
| `UcCardContainer.DialogActionCtnrUID` | 详情容器地址                     | 点击卡片进入详情 |
| `UcCardContainer.DialogKeyDataField`  | 主键字段                       | 向详情页传值   |


![](madora-asset://1cab5e248695c3cc54f1dd5a56567f81d5396c8767b05765fdeefa0f226b4e5f)

搜索需要全屏展示时，为 `UcScopeContainer` 配置 `CssClass=full-page`。

### 详情与编辑页

```text
UcContainer
├─ UcPageTitleContainer
├─ UcFormDetailView
└─ UcButtonContainer → 编辑 / 保存 / 取消
```

将 `UcButtonContainer.RelativeContainer` 指向表单 `ID`。编辑按钮使用 `EDIT`，保存按钮使用 `ADDSAVE` 或 `EDITSAVE`，取消按钮使用 `ADDCANCEL` 或 `EDITCANCEL`。按钮是否显示同时取决于 `RelateOpCode` 权限和 `IsVisibleWhenAdd/Edit/View`。

![](madora-asset://e8a881e4593df0b4f4218afbf499f5f82fd2734a9c5b68b7183c81ff8925986d)

### 工作流详情页

```text
UcContainer
├─ UcPageTitleContainer
├─ UcFormDetailView
├─ RefContainer / UcTab → UcWorkFlow
└─ UcButtonContainer → SUBMIT / UNDOSUBMIT
```

移动端可复用云端流程配置。工作流通过 `RefContainer` 或 `UcTab` 引入详情页，按钮仍遵循关联容器、操作权限和页面模式规则。

![](madora-asset://e1b29c4c0798acbeb032a70ca85d950ca654d20051d92e4e575f38e052ec9de1)

### 文件详情页

```text
UcContainer
├─ UcPageTitleContainer
├─ UcFormDetailView
└─ RefContainer → UcFileContainer
```

`ViewType=thumbnail` 配合 `ReferToCtnrUID=fs_file.pda.UcFileThumbnailList` 显示缩略图。`TitleRSCode` 为空时不显示标题和上传按钮；iOS 不显示 `AddCommandRSCode` 对应的上传按钮。

![](madora-asset://f09ce690731e9104def0097d5b68ac28da6e79d2dc541df888b9d045cc4e6ca9)

### 多行编辑页（组合示意）

```text
主页面：UcFormDetailView + UcJsGridContainer + UcButtonContainer
选择弹窗：UcPageListContainer + UcButtonContainer
```

弹窗按钮组的 `RelativeContainer` 指向弹窗列表，确认按钮配置 `OnClientClick=confirmMutiSelect`，将选中数据回填到主页面的 `UcJsGridContainer`。

![](madora-asset://d0c677f00160b8673528adc50fdc32e0da5da006dfe5972b2d69a2fe48ceb80b)

### 数据看板页（组合示意）

```text
UcContainer
├─ UcPageTitleContainer
├─ UcBannerContainer
├─ UcCardContainer（指标）
└─ UcChartContainer
```

轮播图负责动态内容，卡片展示指标，图表通过 `ChartType` 选择基础类型并用 `ExtraConfig` 调整。点击跳转需配置 `OnClientClick`、`DialogActionCtnrUID` 和 `ParamterDataField`。

## 页面容器

### 最外层容器 UcContainer

`UcContainer` 是移动端页面的装配入口，本身负责承载其他容器。常见组合是页面标题、页签组、卡片列表和按钮组。

**典型配置步骤**

1. 在最外层 `UcContainer` 中引用 `UcPageTitleContainer` 和 `UcTabGroup`。
2. 在 `UcTabGroup` 中引用各业务 `UcContainer`。
3. 在业务 `UcContainer` 中引用 `UcPageListContainer` 和 `UcButtonContainer`。

![](madora-asset://487450be38b495cd47ebdaf10ee27574f3d05f81f02d84a0a26dcadf67f0a205)

### 页面标题 UcPageTitleContainer

移动端标题由左侧默认返回图标、中间标题和可选的右侧子控件组成。右侧可放置搜索图标或其他操作控件。


| 属性            | 示例值                | 说明       |
| ------------- | ------------------ | -------- |
| `TitleRSCode` | 资源代码               | 配置页面标题   |
| `CssClass`    | `pithy-title-erow` | 使用简洁标题样式 |


标题内常用的 `UcImage` 属性：


| 属性                    | 示例值                                  | 说明                              |
| --------------------- | ------------------------------------ | ------------------------------- |
| `Position`            | `right`                              | 控件位置，可选 `left`、`right`、`middle` |
| `DialogActionCtnrUID` | `FnCode.FnParameter.CtnrUID`         | 点击后打开的容器                        |
| `ClientActions`       | `{"onclick":"showSearch"}`           | 客户端事件映射                         |
| `ImageUrl`            | `../assets/images/common/search.png` | 图片路径                            |


![](madora-asset://f3afc106ec4fc9df8d5e60202c9508dbe3bff1dd75f95bfc2970ac14797ba1a7)

查找容器在移动端默认为弹窗。需要全屏展示时，为 `UcScopeContainer` 配置 `CssClass=full-page`；与云端不同的是，需要在 `UcPageListContainer.ScopeCtnr` 中填写查找容器的 `CtnrUID`。

### 页签组 UcTabGroup

`UcTabGroup` 用于在一个页面内组织多个业务区域。每个页签可引用不同的 `UcContainer`，再由该容器承载列表或按钮组。

> 原手册提到页签可显示角标，但没有给出属性名、数据格式和示例，相关配置待补充。

## 数据展示与编辑容器

### 卡片容器 UcCardContainer

`UcCardContainer` 的布局方式类似表单，但通常以 `VIEW` 模式展示，不用于编辑。卡片可以包含 `UcLabel`、`UcBoundField` 和 `UcButton`，也可以通过点击打开详情容器。


| 属性                    | 示例值                          | 说明                   |
| --------------------- | ---------------------------- | -------------------- |
| `TotalCols`           | `4`                          | 卡片总列数                |
| `ColsWidth`           | `25%,25%,25%,25%`            | 各列宽度，使用逗号分隔          |
| `DialogActionCtnrUID` | `FnCode.FnParameter.CtnrUID` | 点击卡片后打开的容器；无跳转时不配置   |
| `DialogKeyDataField`  | 数据字段名                        | 传递目标页面所需的 `KeyValue` |


`UcBoundField` 可配置 `CssClassField`，根据返回数据切换文字或背景样式，例如用红色、绿色区分状态。

![](madora-asset://cd3d31ebce8d47b213c314f460ee5c55ae92fa80f3f8a652f127e14ebaad9c59)

### 卡片列表 UcPageListContainer

`UcPageListContainer` 引用 `UcCardContainer` 后，以卡片列表形式展示数据。它类似云端的 `UcGridviewContainer`，支持 `WhereSqlText`、`OrderBySqlText` 等属性；配置 `TitleRSCode` 后，可作为 `UcTab` 的展示名称。

**使用存储过程提供分页数据**

1. 创建带分页入参和 `totalCount` 出参的存储过程。
2. 配置 `StoredProcDBAction`，并设置 `OutParameter=totalCount`。
3. 配置 `UcPostContainer`，此处不配置 `OutParameter`。
4. 将 `UcPageListContainer.DataSourceCtnrUID` 指向 `UcPostContainer`。

![](madora-asset://81b28bc8d4b38d4e222b4794e15a2085752964d83d6b3f801fcda1f996d3e827)

### 表单 UcFormDetailView

移动端表单的基本配置与云端一致。编辑模式显示分隔线，查看模式不显示分隔线。


| 属性                          | 示例值                       | 说明                |
| --------------------------- | ------------------------- | ----------------- |
| `ColsWidth`                 | `13%,20%,13%,20%,13%,21%` | 各列宽度，使用逗号分隔       |
| `TotalCols`                 | `6`                       | 表单总列数             |
| `WhereSqlText`              | SQL 条件                    | 没有主键时使用的自定义过滤条件   |
| `DataSourceDBActionCtnrUID` | DBAction 容器               | 常规配置无法取值时，自定义返回数据 |


表单可使用 `UcTextBox`、`UcDatePicker`、`UcDropDownList`、`UcCheckBoxListField`、`UcRadioButtonList`、`UcImage`、`UcImageField` 和 `UcStepperField`。

### 多行编辑 UcJsGridContainer

移动端 `UcJsGridContainer` 的组件和属性用法与云端大致相同，支持普通多行编辑、弹窗选择数据回填，以及通过 `RefContainer` 引用表单。


| 属性                     | 说明                    |
| ---------------------- | --------------------- |
| `IsHideTitle`          | 是否隐藏表头，默认 `false`     |
| `IsShowLineNumber`     | 是否显示行号，默认不显示          |
| `IsHideADD`            | 是否隐藏新增按钮              |
| `IsHideDELETE`         | 是否隐藏删除按钮              |
| `IsHideDELETE_ALL`     | 是否隐藏“全部删除”，默认 `false` |
| `IsHideDeleteAllField` | 根据返回字段判断是否隐藏“全部删除”    |


弹窗选择时，在弹窗按钮上配置 `OnClientClick=confirmMutiSelect`，可将选中数据回填到 `UcJsGridContainer`。

![](madora-asset://0ac297f3fe733f284a26abef7df14e9670f5b2cfc984cf4d32834f02d1a365f9)

> `UcGridviewContainer` 在原移动端手册中只有标题，没有用途、属性或示例，暂不将其视为已完成的移动端组件说明。

## 操作与权限组件

### 按钮组 UcButtonContainer

`UcButtonContainer` 可包含多个 `UcButton`。它通过 `RelativeContainer` 关联目标容器，并从目标容器获取操作权限。


| 属性                  | 示例值      | 说明                                  |
| ------------------- | -------- | ----------------------------------- |
| `RelativeContainer` | `C61471` | 关联容器的 `ID`；目标为页面、列表或表单时，分别使用对应层级的权限 |


### 按钮 UcButton


| 分类  | 属性                           | 示例值或可选值                               | 说明                           |
| --- | ---------------------------- | ------------------------------------- | ---------------------------- |
| 行为  | `actionType`                 | `dbAction`、`dialogAction`、`jsAction`  | 按钮操作类型                       |
| 行为  | `dbActionCtnrUid`            | `FnCode.FnParameter.CtnrUID`          | 接口容器，一般指向 `UcPostContainer`  |
| 行为  | `DialogActionCtnrUID`        | `FnCode.FnParameter.CtnrUID.PageMode` | 打开的目标容器                      |
| 行为  | `DialogKeyDataField`         | 数据字段名                                 | 向目标容器传递键值                    |
| 行为  | `DialogType`                 | `dialog`、`page`                       | 弹窗或全屏页面，默认 `dialog`          |
| 行为  | `OnClientClick`              | `confirmMutiSelect`                   | 客户端点击函数                      |
| 行为  | `ActionTargetID`             | `C61736`                              | 客户端函数操作的目标容器                 |
| 显示  | `IsVisibleWhenAdd/Edit/View` | `true` / `false`                      | 不同页面模式下是否显示                  |
| 权限  | `IsCustom`                   | `true` / `false`                      | `false` 表示按操作权限控制，默认 `false` |
| 权限  | `RelateOpCode`               | `ADD`、`EDIT`、`DELETE` 等               | 匹配操作权限                       |
| 确认  | `ConfirmMessage`             | 提示文本                                  | 点击后的二次确认消息                   |


权限按钮只有在 `RelativeContainer` 返回的权限中包含 `RelateOpCode`，并且当前页面模式满足可见性属性时才显示。`IsCustom=true` 的自定义按钮不匹配操作权限，只按页面模式可见性控制。

常用客户端操作包括：`EDIT`、`ADDCANCEL`、`EDITCANCEL`、`ADDSAVE`、`EDITSAVE`、`SUBMIT` 和 `UNDOSUBMIT`。

## 业务组件

### 工作流 UcWorkFlow

移动端与云端可以共用同一套流程配置。在详情页中使用 `RefContainer` 或 `UcTab` 引用工作流容器。

移动端文件容器可直接在详情页中通过 `RefContainer` 引用，支持 PDF 和图片的上传与预览。点击预览按钮或文件名会进入文件预览页面。

## 图表与轮播图

### 图表 UcChartContainer

`UcChartContainer` 可通过 `ChartType` 使用预设图表，也可以用 `ExtraConfig` 覆盖或补充 ECharts 配置。支持饼图、环形图、矩阵图、柱状图、堆叠柱状图、仪表盘、水波图、折线图及柱线混合图。


| 属性                      | 说明                 |
| ----------------------- | ------------------ |
| `ChartType`             | 匹配默认图表配置           |
| `OnClientClick`         | 图表项点击事件处理函数        |
| `DialogActionCtnrUID`   | 点击后跳转的容器           |
| `AfterGetContainerData` | 获取数据后的回调函数         |

| `ExtraConfig`           | 覆盖或补充默认 ECharts 配置 |

`ExtraConfig` 与默认配置的合并规则是：同名属性覆盖，默认配置中不存在的属性新增。

## 移动端与云端的关键差异


| 场景   | 移动端行为                                                                 |
| ---- | --------------------------------------------------------------------- |
| 列表展示 | 主要使用 `UcPageListContainer` 引用 `UcCardContainer`，而非云端一览表式展示            |
| 卡片模式 | `UcCardContainer.pageMode` 通常为 `VIEW`，用于只读展示和点击跳转                     |
| 页面标题 | 默认包含返回图标；右侧操作作为子控件并设置 `Position=right`                                |
| 查找容器 | 默认弹窗；`CssClass=full-page` 可改为全屏；在 `UcPageListContainer.ScopeCtnr` 中关联 |
| 文件容器 | 使用 `TitleRSCode` 和 `AddCommandRSCode` 控制标题与上传入口；iOS 不显示上传按钮           |
| 工作流  | 配置可与云端共用，在详情页通过 `RefContainer` 或 `UcTab` 引用                           |
